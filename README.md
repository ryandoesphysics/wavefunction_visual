# wavefunction_visual
3-dimensional visualisation of the probability distribution of the hydrogen atom.
Separating the radial and spherical component of the Hydrogen wavefunction, we obtain radial harmonics and spherical harmonics with equations

$$
Y_{lm}(\theta,\phi) = \Theta_{lm}\Phi_m=(-1)^m\left(\frac{2l+1}{4\pi}\frac{(l-m)!}{(l+m)!}\right)^{1/2}\,P^m_l(\cos\theta)\,e^{im\phi}
$$
